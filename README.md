# Тесер — обновления Android

Официальная публичная раздача установочных файлов «Тесера». Здесь размещаются только подписанные APK и сведения о версиях; основной исходный код и ключи подписи хранятся отдельно.

После первой установки версии 0.3 или новее приложение проверяет обновления при открытии и периодически в фоне. Можно нажать «Проверить обновления». Скачивание и установка требуют действий пользователя; приложение проверяет целостность файла и совпадение подписи.

Актуальная версия указана в [latest.json](latest.json), установочные файлы — в каталоге [apk](apk).

Брифинг — ежедневно в 08:25 Asia/Barnaul; для личного будильника время выбирается отдельно. Yandex Cloud пока не подключён.

Переход со старого debug APK на постоянную release-подпись может потребовать однократной переустановки и повторной настройки разрешений/будильников. Последующие release-обновления сохраняют данные.
