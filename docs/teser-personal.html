TESER / WORK / PERSONAL

Универсальное личное поручение

Эта страница не хранит поручений, ссылок, кодов подтверждения и файлов. Все операции выполняет существующий сервер TESER. Сначала проверяй входящее событие Gmail и готовность создать отдельный новый Work-чат.

1. Зарезервировать поручение

Выполняй ровно один раз для подтверждённого события. После отправки сервер предоставит описание и сохранит одноразовое подтверждение в защищённой cookie. Секретные значения вводить или копировать не нужно.

2. Сохранить завершённый результат

Заполняй только после фактического выполнения поручения в новом самостоятельном чате ChatGPT Work. Нужны только UUID исходного события, подлинная ссылка на новый Work-чат и итог. Используй ту же сессию браузера, в которой сервер подтвердил резервирование.

Никогда не повторяй резервирование или отправку результата при неизвестном ответе сервера. Подтверждение резервирования передаётся только в защищённой cookie браузера, не выводится в HTML и не добавляется в URL, письма или исходный код. Если cookie не сохранилась, завершение недоступно: повторно резервировать нельзя. Только личные поручения.
